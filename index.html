Hosting this page

This dashboard is one self-contained page — the videos travel with it, and it needs no server, account, or database. To put it online:

  1. Save this page as a single .html file (in Muse, use the artifact's export; in a browser, File → Save Page As).
  2. Drop the file onto any static host — Netlify Drop, GitHub Pages, Cloudflare Pages, or any web space you already have.
  3. Open the link it gives you. Everything works offline-capable in the browser; practiced checkmarks are kept only while the page stays open.
